# 鲤创空间运营管理平台

众创空间管理系统前端 MVP，覆盖企业与人员、门禁任务、通知回执、会议室预约、共享办公、订单支付、虚拟空间和数据大屏。

## 运行方式

这是一个零依赖静态 Web 应用，可直接双击 `index.html` 打开。

也可以在本目录启动本地静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前能力

- 企业和人员资料的新增、编辑、删除、搜索与导出
- 人员变更自动生成门禁人工处理任务
- 门禁审批、处理状态和接口预留说明
- 微信/邮件通知发布、确认率统计和再次提醒
- 会议室时段展示、冲突检查、内部/外部预约
- 共享办公外部预约，自动生成订单和临时门禁审批
- 线上/线下支付台账、线下收款确认和退款流程
- 可交互的 5F 虚拟空间示意
- 运营总览和管理驾驶舱
- 角色演示与数据隔离：入驻企业管理员仅查看本企业数据，管理层为只读
- 浏览器本地存储数据，无需数据库即可演示完整流程

## 后续正式开发建议

当前版本用于需求确认与业务演示。生产环境应增加服务端 API、关系数据库、统一身份认证、RBAC 数据权限、文件存储、微信/邮件/支付平台接口、审计日志和自动化测试。门禁设备升级后，可将现有人工任务流替换为设备接口同步。
